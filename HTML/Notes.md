## WCAG

## Semantic HTML

- Semantic HTML means using HTML elements that clearly describe their meaning and purpose.

- Semantic HTML improves accessibility, SEO, and code readability. 

- Non-Semantic (Bad)

  ```html
  <div class="header"></div>
  <div class="nav"></div>
  <div class="content"></div>
  ```

- Semantic (Good)

```html
<header></header>
<nav></nav>
<main></main>
```

**Why Sematic HTML matters**

- Accessibility: Screen readers understand page structure. 

- SEO: Search engines understand content hierarchy 

- Maintainability: Code is readable & self-explanatory 

**Common Semantic Tags**

| Tag         | Meaning                |
| ----------- | ---------------------- |
| `<header>`  | Page or section header |
| `<nav>`     | Navigation links       |
| `<main>`    | Main content           |
| `<section>` | Logical section        |
| `<article>` | Independent content    |
| `<aside>`   | Sidebar                |
| `<footer>`  | Footer                 |


## HTML5 new features 

- Multimedia: `<audio>`, `<video>`
- Graphics: `<canvas>`, `<svg`>
- Forms: New inputs - email, date, etc
- Semantic tags: `<header>`, `<footer>`, `<article>`
